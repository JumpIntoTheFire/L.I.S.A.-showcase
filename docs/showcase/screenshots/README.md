# Screenshots

Drop showcase screenshots in this folder. These are referenced by the top-level
`README.md` and `../memory-system.md`.

Expected files:

| Filename | What | Used in |
|---|---|---|
| `dashboard.png` | Mission Control page — stats, session list, HUD theme | README hero |
| `n8n-workflow.png` | Full n8n graph (88 nodes) | README pipeline section |
| `footer-quote.png` | Einstein quote footer | README footer |
| `session-detail.png` *(optional)* | A completed session's 21 agent outputs | README example-run section |
| `approval-gate.png` *(optional)* | Ethics or architecture approval banner | README memory/gate section |

Before dropping a screenshot, check it does not contain:

- Real usernames, email addresses, or admin accounts
- Console/dev-tools output with tokens or cookies
- Browser bookmarks or tab titles revealing paths/projects
- System clock or notification areas revealing location
- File-manager windows showing the absolute project path
